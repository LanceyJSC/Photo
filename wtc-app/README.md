# WTC — Music Television (iOS + Android)

Expo / React Native app. Always-on MTV-style music video channels with VJ lower-thirds, TV static, a station ident and a channel guide.

## Run on your phone
1. Install **Expo Go** from the App Store / Play Store.
2. On a computer: `cd wtc-app && npm install && npx expo start`
3. Scan the QR code with your phone camera (iOS) or Expo Go (Android).

Edit `src/channels.ts` to change the channel lineup.
